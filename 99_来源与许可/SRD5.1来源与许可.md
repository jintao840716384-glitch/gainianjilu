# SRD 5.1 来源与许可

## 规则基准

本仓库选择 D&D 5e（2014）作为唯一基础版本，并以 Wizards of the Coast 发布的 System Reference Document 5.1（SRD 5.1）作为可公开收录的完整基准。

官方来源：
- System Reference Document 5.1：`https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf`
- Creative Commons Attribution 4.0：`https://creativecommons.org/licenses/by/4.0/legalcode`

## 必要署名

This work includes material taken from the System Reference Document 5.1 (“SRD 5.1”) by Wizards of the Coast LLC and available at https://dnd.wizards.com/resources/systems-reference-document. ## 结构化数据来源

`02_规则内容库` 使用 `5e-bits/5e-database` 的 2014 英文结构化数据生成机器可读条目：

`https://github.com/5e-bits/5e-database`

该项目代码采用 MIT License，其底层规则内容来自 D&D 5e SRD。仓库中的同步脚本只调整目录、拆分条目和生成索引，不把第三方数据库声明为规则权威来源。

## 权威顺序

1. 官方 SRD 5.1 原文；
2. 本仓库 `01_核心规则` 的中文执行整理；
3. `02_规则内容库` 的结构化条目；
4. 其他资料。

如结构化数据与官方 SRD 5.1 不一致，以官方 SRD 5.1 为准并修正本仓库。

## 覆盖边界

SRD 5.1并不包含2014年《玩家手册》《地下城主指南》《怪物图鉴》中的全部商业内容。本仓库可公开做到的是：

- 完整收录SRD 5.1允许公开使用的规则与内容；
- 为非SRD内容保留按需引用接口；
- 不复制未获许可的官方书籍、冒险模组或扩展资料全文。

因此，“完整”指SRD 5.1基准完整，而不是公开复制所有2014版商业规则书。
