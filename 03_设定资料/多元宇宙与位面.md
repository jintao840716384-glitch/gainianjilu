# 多元宇宙与位面

本文件整理SRD 5.1的通用位面框架。它是可供模组引用的设定资料，不强制所有世界使用相同宇宙结构；当前模组明确采用其他宇宙观时，以模组设定为准。

## 位面结构

### 物质位面

物质位面是凡人生命与普通物质存在的主要层面。不同战役世界均可作为物质位面中的独立世界；它们可以拥有不同历史、技术、魔法和神祇体系。

### 物质位面的回响

某些世界将以下层面作为物质位面的平行回响：

- 妖精荒野：生命、情感与自然魔法更浓烈的回响；
- 影界：衰败、阴影与负面情绪更浓烈的回响。

是否存在、名称、环境效果与旅行方式由当前模组或世界设定决定。

### 过渡位面

过渡位面主要连接其他位面。

- 以太位面：与物质位面及内层位面的对应地点重叠；边境以太可观察相邻位面，深层以太连接更远区域。
- 星界：思想与梦境的银色空间，常用于前往外层位面。

以太化、异界传送、星界投射、真实视觉等法术与感官只按各自条目提供的范围和能力运行，不自动获得完整位面知识。

### 内层位面

内层位面提供构成物质世界的元素物质与能量：

- 气元素位面；
- 土元素位面；
- 火元素位面；
- 水元素位面。

靠近物质位面的边缘区域可能混合多种元素并适合生存；越深入越接近纯粹元素，环境通常更加极端。最外缘的元素相互混合形成元素混沌。

### 外层位面

外层位面体现思想、精神与阵营理念，常作为神祇、天界生物和邪魔的领域。善良倾向的外层位面通常称为上层位面，邪恶倾向的称为下层位面。

SRD框架使用十六个主要外层位面，对应八种非绝对中立阵营及其间的过渡倾向：

| 位面 | 主要倾向 |
|---|---|
| 七重天堂山 | 守序善良 |
| 双生天堂 | 守序善良／中立善良 |
| 极乐境 | 中立善良 |
| 兽乡 | 中立善良／混乱善良 |
| 奔放之野 | 混乱善良 |
| 约瑟园 | 混乱善良／混乱中立 |
| 混沌海 | 混乱中立 |
| 喧嚣深渊 | 混乱中立／混乱邪恶 |
| 无底深渊 | 混乱邪恶 |
| 卡瑟利 | 混乱邪恶／中立邪恶 |
| 灰色荒野 | 中立邪恶 |
| 焦炎地狱 | 中立邪恶／守序邪恶 |
| 九层地狱 | 守序邪恶 |
| 修罗场 | 守序邪恶／守序中立 |
| 机械境 | 守序中立 |
| 世外桃源 | 守序中立／守序善良 |

位面名称、层数、环境与阵营效果属于设定内容；没有具体条目时，不得根据名称自动施加伤害、状态或强制人格变化。

### 其他位面

- 正能量位面与负能量位面：生命与死亡能量的极端源头；是否作为独立位面使用由世界设定决定。
- 远域：位于已知多元宇宙之外的异质现实；具体影响必须由模组或效果条目定义。
- 半位面：具有自身规则的小型异次元空间，可由法术、神祇、自然现象或其他力量形成。

## 位面旅行

位面旅行只在具备明确通道时发生：

- 法术或能力，例如异界传送、传送门、以太化、星界投射；
- 魔法物品；
- 固定或移动的位面传送门；
- 模组明确的裂隙、漩涡、地点或仪式。

每个通道记录：

- 起点与目的地；
- 是否双向；
- 激活条件、钥匙、口令或调谐物；
- 精确度与可能偏差；
- 持续时间、关闭条件和使用限制；
- 是否允许携带其他生物或物品。

不知道目的地、调谐条件或传送门规则时，不得默认通道可用。

## 位面环境

每个位面或区域的特殊环境必须由模组或设定明确给出，例如：

- 重力、时间和距离；
- 光照、空气、温度与地形；
- 魔法增强、阻碍或失效；
- 阵营共鸣；
- 休息、死亡和复活变化；
- 随机遭遇和原住生物。

通用位面介绍本身不产生机械效果。只有明确规则条目才能修改角色数值、状态、法术或行动。
