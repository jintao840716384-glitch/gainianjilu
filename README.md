# AI主持 D&D 5e（2014）执行规则

本仓库是供 AI 主持人读取和执行的 D&D 5e（2014）兼容规则指令集。

## 目标

- 在单人玩家与 AI 主持环境中稳定运行 D&D 5e。
- 保留 d20、六项属性、熟练、职业、战斗、状态、休息、成长、装备与法术等核心机制。
- 兼容官方及民间 5e 模组；模组明确规则按其原文执行。
- 压缩重复说明，只保留会影响 AI 判断、结算、状态维护和模组兼容的内容。

## 仓库边界

包含：
- 5e 核心规则的执行表达；
- AI 主持与裁决约束；
- 角色、战役和存档所需数据模板；
- 外部模组读取与兼容规则。

不包含：
- 面向人类阅读的教程、设计说明和背景解释；
- 固定 NPC 队友系统、队伍关系系统或其他单人扩展玩法；
- 原创世界观、战役内容及未经明确采用的自创规则。

## 执行原则

1. 不改变 D&D 5e（2014）核心数学与通用术语。
2. 规则、模组内容、当前状态和临时裁决必须分离。
3. 存档只记录事实与状态，不得覆盖规则。
4. 临时裁决只处理当前缺口，不自动成为永久规则。
5. 同一规则只保留一个正式定义；速查文件只能引用或压缩，不得另立版本。
