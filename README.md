# D&D 5e（2014）AI执行规则书

本仓库是供 AI 直接查询和执行的 D&D 5e（2014）兼容规则书。

规则包修订以当前 Git 提交 SHA 或发布标签为准；未标记版本视为开发版。

## 目标

- 保留 D&D 5e（2014）的核心数学、术语和运行机制。
- 将规则压缩为条件、公式、步骤、效果与例外，减少面向人类的教学和重复解释。
- 兼容官方及民间 5e 模组；模组明确规则仅在其适用范围内覆盖通用规则。
- 同一机制只保留一个正式定义，避免 AI 同时读取相互重叠的版本。

## 仓库边界

包含：
- 通用判定、角色、成长、探索、战斗、状态、休息、死亡、装备与施法规则；
- 维持 2014 版模组兼容所需的最小规则覆盖原则；
- 经明确收录的规则内容资料。

不包含：
- AI 主持协议、输出规范、掷骰权限、存档流程、NPC管理或世界状态维护；
- 面向人类阅读的教程、设计说明和背景解释；
- 固定 NPC 队友系统、关系系统、自动难度调整及其他单人扩展玩法；
- 原创世界观、战役剧情及未经明确采用的自创规则。

## 编写原则

1. 不改变 D&D 5e（2014）核心数学与通用术语。
2. 优先压缩表达，不以简化为由删除会影响结算或模组兼容的规则。
3. 具体职业、法术、怪物、物品等内容必须来自明确资料，不得根据名称猜测。
4. 同一规则只保留一个正式定义；索引只负责定位，不重复定义规则。
