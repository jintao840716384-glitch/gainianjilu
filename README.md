# D&D 5e（2014）AI执行规则书

本文件是仓库的**唯一启动入口与读取路由**。打开仓库根链接后，先执行本文件；不要从目录顺序猜测优先级。

## 强制读取约束

1. 不得递归扫描、批量打开或一次性载入整个仓库。
2. 先判断当前任务，再按下方路由读取最小文件集合。
3. 不知道具体条目路径时，先读对应分类索引；不得遍历整个条目目录。
4. 同一机制只读取一个核心规则文件；索引和内容条目不重复定义通用规则。
5. 具体种族、职业、子职业、背景、专长、法术、装备、怪物和魔法物品必须读取准确条目，不得依靠模型记忆补造。
6. 内容条目的英文结构化字段用于精确结算；可在输出时翻译，但不得改变数值、触发、目标、持续时间和例外。
7. 只在当前行动需要时读取规则；场景结束后无需保留无关正文。
8. 本仓库只提供规则与规则内容，不提供AI主持方式、存档流程、队友系统或战役世界状态。

## 规则基准

- 基础版本：D&D 5e（2014）。
- 可公开完整基准：System Reference Document 5.1（SRD 5.1）。
- 不自动混入2024版、电子游戏版本或其他版本的同名内容。
- 规则来源与覆盖顺序读取：`01_核心规则/规则版本与覆盖.md`。
- 来源、许可和完整性边界读取：`99_来源与许可/SRD5.1来源与许可.md`。

## 内容数据库读取

入口：`02_规则内容库/README.md`

内容库现有25个分类、2317个独立条目。执行顺序：

1. 读取内容库总索引；
2. 读取对应分类索引，例如`索引/spells.md`或`索引/monsters.md`；
3. 只打开当前需要的一个或少数条目；
4. 结算完成后保留结果，不重复载入条目全文。

示例：

- 施放火球术：法术通则 → 法术索引 → 火球术条目。
- 遭遇食人魔：战斗通则 → 怪物索引 → 食人魔条目。
- 战士升到5级：角色与成长通则 → 职业等级索引 → 战士5级及相关特性条目。

## 仓库结构

- `00_规则索引`：不知道路径时使用，不定义规则。
- `01_核心规则`：通用机制与地下城主规则的中文执行表达。
- `02_规则内容库`：种族、职业、法术、装备、怪物、魔法物品等SRD结构化条目。
- `03_设定资料`：SRD附带的通用神系与位面设定，仅按需读取。
- `99_来源与许可`：来源、署名和合法覆盖边界。

## 仓库边界

包含：

- 2014版通用规则的AI执行表达；
- SRD 5.1允许公开收录的种族、职业、背景、法术、装备、怪物、魔法物品及其他内容；
- SRD历史神系与位面框架；
- 为准确检索而生成的分类索引和结构化条目。

不包含：

- AI主持协议、输出风格、掷骰权限、存档流程、NPC管理或世界状态维护；
- 固定队友、关系系统、自动难度调整等单人扩展玩法；
- 原创世界观和战役剧情；
- 未获许可的2014版商业规则书或官方模组全文。

非SRD内容由当前跑团项目提供合法资料，并按`规则版本与覆盖.md`接入；缺失时不得伪装成已知官方规则。
