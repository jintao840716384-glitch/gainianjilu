# 多职业规则

多职业是可选规则。只有当前战役明确启用时才能增加第二个或更多职业等级。

## 增加职业等级

角色升级时选择提高现有职业或增加一个新职业等级。总等级等于所有职业等级之和；经验阈值、熟练加值、戏法按总等级成长的部分及其他明确引用“角色等级”的效果使用总等级。职业特性通常使用对应职业等级。

增加新职业前，必须同时满足：

- 当前已拥有的每个职业的多职业属性前置；
- 将要加入的新职业的多职业属性前置。

| 职业 | 属性最低要求 |
|---|---|
| 野蛮人 | 力量13 |
| 吟游诗人 | 魅力13 |
| 牧师 | 感知13 |
| 德鲁伊 | 感知13 |
| 战士 | 力量13或敏捷13 |
| 武僧 | 敏捷13且感知13 |
| 圣武士 | 力量13且魅力13 |
| 游侠 | 敏捷13且感知13 |
| 游荡者 | 敏捷13 |
| 术士 | 魅力13 |
| 邪术师 | 魅力13 |
| 法师 | 智力13 |

未满足前置条件时，不能增加该新职业等级；暂时提高属性的效果是否满足前置，以效果是否明确改变实际属性值及其持续状态为准。

## 经验、生命值与生命骰

- 升级所需经验按角色总等级，不按单一职业等级。
- 只有角色总等级为1级时，才能获得某职业的1级生命值最大值。
- 后来加入的新职业按“该职业1级之后的生命值”增加最大生命值。
- 所有职业给予的生命骰共同构成角色生命骰池；同骰型可以合并记录，不同骰型分别记录。
- 短休花费生命骰时，可从任意仍有可用数量的职业生命骰中选择。

## 熟练加值

熟练加值只按总等级决定，不把各职业表中的熟练加值相加。具体数值读取《等级成长规则》。

## 新职业获得的熟练

首次获得非初始职业的等级时，只获得下表熟练；不获得该职业全部1级熟练，也不获得起始装备。

| 新职业 | 获得的熟练 |
|---|---|
| 野蛮人 | 盾牌、简易武器、军用武器 |
| 吟游诗人 | 轻甲；任选一项技能；任选一种乐器 |
| 牧师 | 轻甲、中甲、盾牌 |
| 德鲁伊 | 轻甲、中甲、盾牌；德鲁伊不穿戴金属护甲或使用金属盾牌 |
| 战士 | 轻甲、中甲、盾牌、简易武器、军用武器 |
| 武僧 | 简易武器、短剑 |
| 圣武士 | 轻甲、中甲、盾牌、简易武器、军用武器 |
| 游侠 | 轻甲、中甲、盾牌、简易武器、军用武器；从游侠技能列表选择一项技能 |
| 游荡者 | 轻甲；从游荡者技能列表选择一项技能；盗贼工具 |
| 术士 | 无 |
| 邪术师 | 轻甲、简易武器 |
| 法师 | 无 |

新职业不会给予其起始豁免熟练、全部技能选项、工具、重甲或起始装备，除非该职业特性在取得对应等级时另行给予。

## 获得职业特性

每获得某职业的新等级，取得该职业该等级提供的特性。以下特性有特殊多职业规则。

### 引导神力

- 新职业提供其自身可用的引导神力效果。
- 再次获得“引导神力”本身不会增加使用次数。
- 只有某一职业等级明确提高使用次数时才增加。
- 每次使用时，可选择角色已获得的任一合法引导神力效果。

### 额外攻击

- 从多个职业取得的“额外攻击”不叠加。
- 除非某一版本明确写明更多攻击，额外攻击只使攻击动作进行两次攻击。
- 邪术师祈唤“饥渴魔刃”与额外攻击不叠加。

### 无甲防御

已经拥有一种“无甲防御”后，不能从另一职业再次取得另一种版本。不得在两种公式之间自由切换；只使用首先取得的无甲防御，除非明确规则改变。

## 多职业施法

只有角色从两个或更多职业获得“施法”职业特性时，使用本节共享法术位规则。若多职业角色只有一个职业具有“施法”，完全按该职业规则运行。

### 已知与准备法术

对每个职业分别处理，视为只拥有该职业实际等级的单职业角色：

- 戏法数量；
- 已知法术；
- 准备法术数量；
- 法术书内容；
- 可以学习、准备或替换的法术环级；
- 施法属性和施法法器。

每个法术都关联其来源职业，并使用该职业的施法属性。某职业的施法法器只能替代该职业法术的材料成分，除非能力明确允许交叉使用。

共享高环法术位不使角色自动知道或能够准备该环法术；它只能用于施放实际已知或已准备的较低环法术，并在法术允许时产生升环效果。

### 计算施法者等级

把以下职业等级相加：

- 吟游诗人、牧师、德鲁伊、术士、法师：全部等级；
- 圣武士、游侠：各自等级的一半，向下取整。

只有一个“施法”职业时，不使用本表，继续使用该职业自己的法术位表。

非SRD职业或子职业若对多职业施法者等级另有折算，必须读取其准确合法资料，不得根据名称推断或自动加入三分之一等级。

### 契约魔法

邪术师“契约魔法”的法术位与上述共享法术位分别计算、分别记录并按各自规则恢复。

- 契约魔法法术位可以施放从“施法”职业已知或准备的法术。
- 共享“施法”法术位可以施放已知的邪术师法术。
- 法术必须使用不低于其自身环级的法术位，并按所用法术位环级处理升环。

## 数据记录

多职业角色必须分别记录各职业等级、各职业来源特性、各职业法术、生命骰类型、共享施法位、契约魔法位及不叠加特性。不得只记录总等级后丢失职业分布。
