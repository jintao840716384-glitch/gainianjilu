# 规则版本与覆盖

## 基准

- 基础版本：D&D 5e（2014）。
- 可公开完整基准：System Reference Document 5.1（SRD 5.1）。
- 不自动混入2024版、电子游戏版本或其他版本的同名规则、职业、法术、怪物、物品和特性。

## 运行时覆盖顺序

同一事项存在多个已采用来源时，按以下顺序处理：

1. 当前战役明确采用的自定义、特殊或可选规则；
2. 当前模组在明确适用范围内写出的特殊规则；
3. 当前对象的具体条目，例如具体法术、职业特性、怪物、物品、陷阱或环境效果；
4. 本仓库`01_核心规则`中的通用规则；
5. 仍无规则时作一次性临时裁决。

具体规则只覆盖其明确范围，未覆盖部分继续使用通用规则。角色、模组或存档中的当前数值不是通用规则来源。

## 官方基准与仓库纠错

运行时通常直接读取本仓库，不要求每次重新打开官方PDF。但仓库内容的准确性按以下权威顺序核对：

1. Wizards of the Coast发布的官方SRD 5.1原文；
2. 本仓库`01_核心规则`的中文执行整理；
3. `02_规则内容库`的结构化条目；
4. 其他资料。

如中文通则、结构化条目和官方SRD 5.1互相冲突，以官方原文为准，并修正仓库；不得为了维持旧文本而继续使用已确认错误。

## 内容来源

- 种族、职业、子职业、背景、专长、法术、装备、怪物和魔法物品必须读取对应准确条目。
- 通用规则不能覆盖具体条目中的例外；具体条目也不能凭名称扩展到未写明的效果。
- 不得仅根据模型记忆、电子游戏版本或相邻规则版本补造效果。
- 非SRD内容必须由当前战役提供合法且准确的资料；没有资料时标记缺失，不伪装成官方规则。

## 可选规则

以下规则只有明确启用时才使用：

- 专长；
- 多职业；
- 变体负重；
- 疯狂；
- 其他标记为可选或变体的规则。

变体人类及其他未收入SRD 5.1的2014版内容，只有当前战役提供合法准确资料并明确启用时才能使用。

## 冲突处理

- 先确认是否属于同一版本、同一名称、同一对象和同一适用时机。
- 具体规则优先于一般规则。
- 明确禁止通常优先于一般允许；更具体的例外可以覆盖该禁止。
- 同一效果能否叠加按其原文和通用叠加规则处理，不根据来源数量自动叠加。
- 冲突无法消解时，记录采用来源与适用范围；临时结果不自动改写通用规则。
