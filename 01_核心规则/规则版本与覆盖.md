# 规则版本与覆盖

## 基准

- 基础版本：D&D 5e（2014）。
- 公开完整基准：System Reference Document 5.1（SRD 5.1）。
- 不自动混入2024版或其他版本的同名规则、职业、法术、怪物、物品和特性。

## 规则来源顺序

同一事项存在多个来源时，按以下顺序处理：

1. 当前战役明确采用的特殊规则或可选规则；
2. 当前模组在明确适用范围内写出的特殊规则；
3. 本仓库 `01_核心规则`；
4. `02_规则内容库` 中对应的SRD 5.1条目；
5. 官方SRD 5.1原文；
6. 仍无规则时作一次性临时裁决。

特殊规则只覆盖其明确范围，未覆盖部分继续使用通用规则。

## 内容来源

- 种族、职业、子职业、背景、专长、法术、装备、怪物和魔法物品必须读取对应条目。
- 不得仅根据名称、模型记忆、电子游戏版本或相邻规则版本补造效果。
- 非SRD内容必须由当前战役提供准确资料；没有资料时标记缺失，不伪装成官方规则。

## 可选规则

以下规则只有明确启用时才使用：

- 专长；
- 多职业；
- 变体人类；
- 变体负重；
- 疯狂；
- 其他标记为可选或变体的规则。

## 冲突处理

- 先确认是否属于同一版本、同一名称和同一适用对象。
- 具体规则优先于一般规则。
- “不能”通常优先于“可以”，除非更具体规则明确构成例外。
- 规则冲突无法消解时，记录采用来源与适用范围；临时结果不自动改写通用规则。
