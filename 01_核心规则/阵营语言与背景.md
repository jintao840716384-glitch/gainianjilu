# 阵营、语言与背景

## 阵营

阵营由秩序轴与道德轴组合：

| 阵营 | 执行含义 |
|---|---|
| 守序善良 | 遵循正当规则并主动保护他人。 |
| 中立善良 | 以帮助他人为优先，不固定服从或反对秩序。 |
| 混乱善良 | 依良知行善，反对压迫性约束。 |
| 守序中立 | 以法律、传统、组织或个人准则为优先。 |
| 绝对中立 | 不稳定偏向任一阵营，或主动维持平衡。 |
| 混乱中立 | 以个人自由为优先，不以善恶为固定目标。 |
| 守序邪恶 | 利用制度、纪律或等级谋取自身或集团利益。 |
| 中立邪恶 | 以自身利益为优先，不固定依赖秩序或混乱。 |
| 混乱邪恶 | 依欲望、暴力或破坏行动，拒绝稳定约束。 |

阵营是行为倾向和规则标签，不强制玩家采取某项行动。法术、物品、位面或怪物能力明确引用阵营时，按具体条目执行。

## 语言

- 角色掌握的语言来自种族、背景、职业、专长、训练或其他明确来源。
- 掌握语言通常包括说、读、写；具体能力写明例外时按其说明。
- 不共享语言时，普通语言交流失败；手势、图示、翻译、魔法或检定只能传递其实际能够表达的信息。
- 文字必须使用角色能够阅读的语言或由能力翻译；听见语言不等于能够阅读其文字。
- 密语、暗语、符号系统和心灵感应按具体特性执行，不自动视为普通语言。

标准语言和异域语言的具体列表、文字及典型使用者读取`02_规则内容库/索引/languages.md`。

## 背景

背景通常提供：

- 两项技能熟练；
- 工具熟练和／或语言；
- 一套起始装备；
- 一个背景特性；
- 人物特征、理想、羁绊与缺陷选项。

若背景给予与其他来源重复的技能或工具熟练，改选同类的另一项合法熟练，不重复叠加熟练加值。选择起始金币购买装备时，不获得背景装备包，按《角色系统》处理。

## 自定义背景

使用2014版自定义背景规则时：

1. 选择任意两项技能熟练；
2. 从背景范例提供的类型中，合计选择两项工具熟练或语言；
3. 选择一个已有背景特性；若没有适合角色概念的特性，可为当前背景创建一个同等范围、不会额外授予技能、数值加值、战斗能力或法术的背景特性；
4. 选择一个已有背景的装备包，或使用起始金币购买装备；使用金币时同时放弃职业和背景装备包；
5. 从任意背景范例选择或自行确定两项人物特征、一项理想、一项羁绊和一项缺陷。

自定义背景不能借此获得额外熟练、额外装备、职业特性、种族特性、专长或法术。

## 人物特征

人物特征、理想、羁绊、缺陷和阵营用于描述角色，不替代玩家决定，也不自动触发检定、优势、劣势或强制行为。只有具体规则明确引用时才产生机械效果。
