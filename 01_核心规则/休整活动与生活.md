# 休整活动与生活

## 休整日

休整活动发生在冒险之间。每个计入进度的休整日通常需要投入至少8小时；多个休整日不必连续。记录活动、累计天数、花费、使用的工具／设施、检定和最终成果。

没有列出的活动可以进行，但必须先确定所需时间、成本、资源、检定、风险和可获得结果，不得在结算后倒推条件。

## 生活方式开支

角色每个生活日支付所选生活方式费用。生活方式影响居住条件、社会环境和相关NPC反应，但不自动提供属性加值。

| 生活方式 | 每日费用 |
|---|---:|
| 赤贫 | — |
| 贫困 | 1银币 |
| 俭朴 | 2银币 |
| 舒适 | 1金币 |
| 富裕 | 2金币 |
| 贵族 | 至少4金币 |

- 赤贫生活不支付固定费用，但通常没有稳定住所、食物和安全保障。
- 背景、组织、职业活动或财产可能免费提供某一生活水平；只按明确来源执行。
- 生活费用与研究、训练、材料等活动费用分别支付，除非活动明确包含生活开支。

## 制作非魔法物品

前置条件：

- 熟练相关工具；
- 拥有所需工具、工作场地和特殊材料；
- 物品属于可制作的非魔法物品。

规则：

- 每名合格制作者每个休整日完成最多5金币市场价值的进度。
- 原材料总成本为物品市场价格的一半。
- 物品价值超过5金币时累计进度，达到完整市场价值后完成。
- 多名合格角色可在同一地点共同制作；每人每天各贡献5金币进度。
- 制作期间可免费维持俭朴生活，或以一半费用维持舒适生活。

魔法物品制作不使用本条；只有当前战役明确采用相应魔法物品制作规则时才能制作。

## 从业

角色从事与其能力、熟练或组织身份相符的职业时：

- 通常可免费维持俭朴生活；
- 若所属组织能提供稳定高薪工作，可维持舒适生活；
- 使用表演技能从业且条件允许时，可维持富裕生活。

从业通常只抵消相应生活开支，不自动产生额外金币；额外报酬必须由具体工作、模组或战役规则给出。

## 疗养

连续或累计投入3个休整日疗养后，进行DC15体质豁免。成功时选择一项：

- 结束一个使自身不能恢复生命值的效果；
- 在接下来24小时内，对当前影响自身的一种疾病或毒素进行的豁免具有优势。

疗养不会自动移除伤势、状态、疾病、毒素、力竭或诅咒；只产生上述效果。

## 研究

开始研究前确定：

- 信息是否真实存在且可获得；
- 所需资料、人物、地点或权限；
- 所需休整日；
- 是否需要智力（调查）、魅力（游说）或其他检定；
- 失败、部分成功和重复尝试的后果。

每个研究日额外花费1金币，且仍需支付生活开支。只有达成预先确定的条件时才能获得信息；不存在或被隔离的信息不能因高骰点凭空产生。

## 训练

可训练：

- 一种新语言；或
- 一套工具熟练。

前置条件：找到愿意且有能力的导师，并获得所需设施。标准训练需要250个休整日，每日花费1金币，另计生活开支。完成全部时间和费用后获得对应语言或工具熟练。

职业熟练、技能熟练、豁免熟练、武器护甲熟练、专长、法术和职业特性不能通过本通则训练获得，除非其他明确规则允许。

## 服务与雇佣

- 普通服务、住宿、交通、信使、施法服务和雇工的价格与可用性读取具体地点、模组或装备内容条目。
- 支付价格不等于对方必然同意危险、违法、敌对或超出能力的任务。
- 雇工不自动成为同伴或玩家控制角色；其统计资料、职责、风险和报酬按雇佣内容执行。

## 财产与经营

建筑、船只、商店、组织和其他长期资产只有在当前战役提供明确维护、收入、人员和事件规则时运行。不得依据资产名称自动生成固定收益或忽略维护成本。
