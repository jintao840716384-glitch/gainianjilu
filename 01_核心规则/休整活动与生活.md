# 休整活动与生活

## 休整日

休整活动发生在冒险之间。每个计入进度的休整日必须投入至少8小时；多个休整日不必连续。记录活动、累计天数、花费、工具、设施、检定和成果。

未列出的活动可以进行，但必须在开始前确定所需时间、成本、资源、检定、风险和可获得结果。

## 生活方式开支

生活方式费用包括住宿、食物、饮水、衣物与日常装备维护。角色可按周或按月预付，也可逐日记录。

| 生活方式 | 每日费用 |
|---|---:|
| 赤贫 | — |
| 穷困 | 1银币 |
| 贫困 | 2银币 |
| 俭朴 | 1金币 |
| 舒适 | 2金币 |
| 富裕 | 4金币 |
| 贵族 | 至少10金币 |

- 生活方式影响居住环境、社会接触和相关人物反应，不自动提供属性加值。
- 赤贫没有稳定住所和基本保障；穷困与贫困环境通常具有更高的疾病、暴力、盗窃和法律风险。
- 贵族生活的实际费用可以高于最低值，并可能需要住所、仆从、礼服、交通或社会身份。
- 背景、组织、职业活动、财产或具体地点可提供某一生活方式；只按明确来源执行。
- 研究、训练、材料和其他活动成本与生活开支分别支付，除非规则明确包含。

### 自给自足

角色离开城镇，通过狩猎、觅食、修理装备等方式生活时可以不支付货币，但必须投入相应时间：

- 一般自给活动通常只能维持相当于贫困生活的条件。
- 熟练生存并成功利用当地资源时，可以维持相当于舒适生活的条件。
- 缺少可用资源、遭遇恶劣天气或环境危险时，不能自动获得上述生活条件。

## 制作非魔法物品

前置条件：

- 熟练相关工具；
- 拥有所需工具、工作地点和特殊材料；
- 物品属于可制作的非魔法物品。

规则：

- 每名合格制作者每个休整日完成最多5金币市场价值的进度。
- 原材料总成本为物品市场价格的一半。
- 物品价值超过5金币时，以每日5金币进度累计，达到完整市场价值后完成。
- 多名合格角色可在同一地点共同制作；每人每天贡献5金币进度并共同承担总材料成本。
- 制作期间可免费维持俭朴生活，或以每日1金币维持舒适生活。

魔法物品制作不使用本条；只有当前战役明确采用相应魔法物品制作规则时才能制作。

## 从业

- 从事适合自身能力和熟练的职业，可在工作期间免费维持俭朴生活。
- 所属组织能提供稳定工作时，可免费维持舒适生活。
- 熟练表演并以表演从业时，可免费维持富裕生活。

从业通常只抵消对应生活开支，不自动产生额外金币；额外报酬必须由具体工作或战役内容给出。

## 疗养

投入3个休整日疗养后，进行DC15体质豁免。成功时选择一项：

- 结束一个使自身不能恢复生命值的效果；
- 在接下来24小时内，对当前影响自身的一种疾病或毒素进行的豁免具有优势。

疗养不会自动移除其他伤势、状态、力竭或诅咒。

## 研究

开始研究前确定：

- 信息是否存在且可获得；
- 所需资料、人物、地点或权限；
- 所需休整日；
- 是否需要智力（调查）、魅力（游说）或其他检定；
- 失败、部分成功和重复尝试的后果。

每个研究日额外花费1金币，并另付生活开支。只有达成预先确定的条件时才能获得信息；不存在或不可访问的信息不能因高骰点产生。

## 训练

可训练一种新语言或一套工具熟练。

前置条件：找到有能力且愿意教授的导师，并获得所需设施。训练需要250个休整日，每日花费1金币，另付生活开支。完成全部时间和费用后获得对应语言或工具熟练。

职业熟练、技能熟练、豁免熟练、武器护甲熟练、专长、法术和职业特性不能通过本通则获得，除非其他明确规则允许。

## 服务、财产与经营

普通服务、雇工、交通、贸易和施法服务读取《货币贸易与服务》。建筑、船只、商店、组织和其他长期资产只有在当前战役提供明确维护、收入、人员和事件规则时运行；不得依据资产名称自动产生固定收益。
