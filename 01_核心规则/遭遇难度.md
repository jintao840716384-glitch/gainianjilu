# 遭遇难度

## 难度等级

- 简单：通常不显著消耗资源或造成严重危险，可能损失少量生命值。
- 中等：通常有一两个危险时刻，需要部分治疗或次数型资源，但预期无伤亡。
- 困难：可能使较弱角色退出战斗，存在少量死亡风险。
- 致命：可能造成一名或更多角色死亡；失败风险真实存在，需要良好战术与资源。

这些是估算，不是结果保证。角色构筑、剩余资源、地形、先攻、怪物克制和玩家策略都会改变实际难度。

## 计算遭遇难度

1. 按每名角色等级取得四项阈值。
2. 分别合计全队的简单、中等、困难、致命阈值。
3. 合计所有实际参战怪物的基础XP。
4. 依据怪物数量对总XP使用数量倍率，得到“调整后XP”。
5. 将调整后XP与队伍阈值比较：达到某阈值但低于下一阈值时，属于该难度；低于简单阈值则低于简单，达到或超过致命阈值则为致命。

调整后XP只用于估算难度，不改变击败怪物实际获得的XP。

## 怪物数量倍率

| 参战怪物数量 | 倍率 |
|---:|---:|
| 1 | ×1 |
| 2 | ×1.5 |
| 3-6 | ×2 |
| 7-10 | ×2.5 |
| 11-14 | ×3 |
| 15或更多 | ×4 |

CR显著低于其他怪物、且不会明显影响行动经济或战场的生物可不计入倍率数量；不能仅因其数值低就自动忽略。

## 队伍人数修正

上述规则以3至5名角色为基准：

- 少于3名角色：使用数量表中高一档倍率；单个怪物使用×1.5，15只以上使用×5。
- 6名或更多角色：使用低一档倍率；单个怪物使用×0.5。

单人角色必须使用“少于3人”修正，但该估算仍不能保证安全。高于角色等级的怪物可能以一次攻击直接击倒低等级角色，应额外检查最大单次伤害、控制能力和豁免DC。

## 多阶段与增援

- 角色无法在阶段之间短休时，分别计算每一波难度，并考虑连续消耗。
- 若多阶段遭遇的调整后XP合计高于队伍冒险日预算的三分之一，整体威胁通常高于各阶段单独难度之和。
- 尚未确定是否参战的敌人不计入当前波；满足触发后作为后续波重新评估。

## 情境调整

若一方拥有另一方没有的显著优势或劣势，可把估计难度上调或下调一级。常见因素：

- 一方被突袭；
- 一方拥有掩护而另一方没有；
- 角色无法看见敌人；
- 一方持续承受环境伤害；
- 角色被悬挂、束缚、限制移动或处于明显不利位置；
- 高低差、狭窄通道、危险地形和目标保护任务。

双方各有相当优劣时可以抵消。不得因为估算结果不符合预期而改写怪物数据、骰点或已建立地形。

## 使用边界

- 官方或民间模组已给出遭遇时，默认按模组运行，不自动缩放。
- 调整遭遇必须是战役明确采用的独立决定，不属于本规则的自动效果。
- 经验阈值衡量战斗威胁，不衡量谜题、社交、陷阱和剧情后果。
