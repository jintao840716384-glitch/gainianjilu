# 判定系统

## d20判定类型

只在结果不确定且成败会产生实际差异时掷骰。

- 属性检定：`d20 + 对应属性修正 + 熟练加值（适用时） + 其他修正`，与DC或对抗结果比较。
- 攻击检定：`d20 + 对应属性修正 + 熟练加值（熟练该武器、法术或攻击时） + 其他修正`，与目标AC比较。
- 豁免检定：`d20 + 对应属性修正 + 熟练加值（拥有该豁免熟练时） + 其他修正`，与效果DC比较。

熟练加值在同一结果中最多加入一次；专精等效果按其规则倍增该次熟练加值。属性检定和豁免的自然20、自然1不自动成功或失败；攻击检定见《战斗系统》。

## 六项属性

属性修正：`向下取整((属性值 - 10) / 2)`。

### 力量

衡量身体力量、运动训练与施加蛮力的能力。

常见直接检定：强开门窗、挣脱束缚、挤过狭窄通道、推翻重物、抓住被拖动物体、阻止重物移动。

**运动：**困难攀爬、跳跃或游泳；在湍流中保持位置；抵抗被推、拉或拖入危险；擒抱和推撞按《战斗系统》处理。

力量通常用于近战武器和投掷武器的攻击与伤害。负重、推拖举上限读取《装备规则》。

### 敏捷

衡量灵活、反应、平衡与精细动作。

- **特技：**在冰面、绳索、摇晃甲板等环境保持平衡；翻滚、空翻、潜跃等技巧动作。
- **巧手：**藏匿或调包物品、扒窃、细微手上把戏。
- **隐匿：**避开视觉和听觉、潜行、躲藏、悄然接近或离开。

常见直接检定：操控失控载具、开锁、拆除机关、捆绑或挣脱绳索、演奏弦乐器、制作微小精细物件。使用工具时只有具备对应工具熟练才加入熟练加值。

敏捷通常用于远程武器以及具有灵巧属性的武器攻击与伤害。先攻是敏捷检定；护甲等级是否加入敏捷修正按护甲条目执行。

### 体质

衡量健康、耐力与生命力。体质通常没有关联技能。

常见检定：长时间屏息、行军或劳动、缺少睡眠、食物或饮水、抵抗长时间饮酒等。疾病、毒素、专注和环境影响通常使用体质豁免，不应误写为体质检定。

体质修正影响生命值；永久变化时按角色总等级追溯调整最大生命值。

### 智力

衡量推理、记忆、知识与演绎能力。

- **奥秘：**法术、魔法物品、奥术符号、魔法传统、位面及位面生物知识。
- **历史：**历史事件、传奇人物、古代王国、战争、文明与遗迹知识。
- **调查：**从线索推断结论、分析机关或结构、寻找隐藏物体的逻辑位置、判断伤口或建筑弱点。
- **自然：**地形、植物、动物、天气和自然循环知识。
- **宗教：**神祇、仪式、祈祷、教会等级、圣徽和秘密教团知识。

常见直接检定：无语言沟通、估价、制作伪装、伪造文书、回忆行业知识、进行技巧型游戏。

### 感知

衡量对周围环境的感知、直觉和经验判断。

- **驯兽：**安抚家养动物、判断动物意图、控制受惊坐骑或执行危险骑乘动作。
- **洞悉：**从语言、表情、习惯和肢体动作判断意图、情绪或谎言迹象；不会自动读取思想或确定全部真相。
- **医药：**稳定濒死生物、诊断疾病或伤势；治疗能力必须来自明确规则或资源。
- **察觉：**通过视觉、听觉或其他感官发现生物、物体、声音、痕迹和易忽略细节。
- **生存：**追踪、狩猎、导航、辨认自然危险、预测天气和发现生物活动迹象。

常见直接检定：凭直觉判断行动方向、辨认看似生物是否为亡灵等。

### 魅力

衡量自信、表现力、领导力与影响他人的能力。

- **欺瞒：**口头或行为隐瞒真相、误导、冒充身份、维持谎言或骗局。
- **威吓：**通过威胁、敌意或暴力施压；成功不等于目标无条件服从。
- **表演：**音乐、舞蹈、演戏、讲故事等娱乐表现。
- **游说：**以礼仪、善意、合理请求、谈判或鼓舞影响他人。

常见直接检定：寻找最适合打听消息的人、融入人群并掌握谈话主题。社交检定不能强制目标实施其绝不接受的行为，除非魔法或能力明确允许。

## 技能与属性组合

技能表示熟练领域，不限制尝试。根据行动实际方式选择属性；合理时可以使用非默认组合，例如力量（威吓）或智力（医药）。更换属性不会改变角色是否拥有该技能熟练。

同一行动同时符合技能熟练和工具熟练时，熟练加值仍只加入一次；具体能力明确给予额外收益时按其规则执行。

## 常用DC

| 难度 | DC |
|---|---:|
| 非常简单 | 5 |
| 简单 | 10 |
| 中等 | 15 |
| 困难 | 20 |
| 极难 | 25 |
| 近乎不可能 | 30 |

已有模组、法术、怪物、物品或陷阱给出DC时使用其数值，不重新估算。

## 优势与劣势

- 优势：掷两个d20，取较高值。
- 劣势：掷两个d20，取较低值。
- 多个优势或多个劣势不增加额外d20。
- 同时存在优势和劣势时全部抵消，只掷一个d20。
- 允许重掷、替换骰点或掷额外骰的能力按其触发时机执行，不等同于优势或劣势。

## 被动检定

被动值：`10 + 该检定通常适用的全部修正`。

该检定具有优势时+5；具有劣势时-5。被动检定用于反复执行的行动，或结果不应公开的察觉、判断等情况。

### 隐匿与发现

- 只有环境允许时才能躲藏；不能躲避能清楚看见自己的生物。
- 躲藏时进行敏捷（隐匿）检定，其结果持续到被发现或停止躲藏。
- 主动搜索者以感知（察觉）与隐匿结果对抗；未主动搜索者通常以被动感知比较。
- 制造明显声音、主动暴露位置或发动攻击通常会暴露位置；隐形允许尝试躲藏，但不消除声音、足迹或其他迹象。
- 轻度遮蔽和重度遮蔽的视觉影响读取《探索系统》。

## 对抗与协作

- 对抗检定：双方进行适用属性检定，较高者获胜；平局维持现状。
- 协助：只有协助者能够独立尝试且合作确实有效时，主执行者获得优势；战斗中通常使用协助动作。
- 团体检定：所有参与者分别检定；至少一半成功则团体成功。

## 执行顺序

1. 判断是否需要判定；确定为属性检定、攻击检定或豁免。
2. 确定适用属性、技能、工具或攻击方式。
3. 确定熟练、优势、劣势及其他修正。
4. 在掷骰前确定DC、AC或对抗对象。
5. 掷骰并结算。
6. 按当前情境执行成功或失败结果；不得预设失败必然推进剧情或关键线索必然获得。
