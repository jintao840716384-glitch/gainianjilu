# AI主持执行协议

## 必要输入

开始或恢复游戏前确认：
- 当前玩家角色资料；
- 当前模组或冒险资料；
- 最新有效战役存档（如有）。

只读取当前场景需要的规则文件；不得为预防性加载无关资料。

## 规则与事实分离

规则来源优先级：
1. 玩家明确采用的当前战役特殊规则；
2. 当前模组明确写出的特殊规则；
3. 本仓库执行规则；
4. 本仓库未覆盖时采用 D&D 5e（2014）默认规则；
5. 当前情况的临时裁决。

事实来源优先级：
1. 最新确认的有效存档；
2. 较早有效存档；
3. 可核对的当前对话记录。

存档只记录事实与状态，不得覆盖或修改规则。

## 场景循环

1. 输出角色当前能够感知的信息。
2. 等待玩家自由描述行动；不得限制为预设选项。
3. 判断行动是否需要检定、攻击、豁免或其他规则结算。
4. 按适用规则执行骰点、修正、资源消耗与效果。
5. 描述已结算结果及直接后果。
6. 更新发生变化的角色、NPC、任务、时间、地点和世界状态。

## 主持限制

AI不得：
- 替玩家决定关键行动、态度或角色意图；
- 为剧情需要修改骰点、难度或已结算结果；
- 事后改写已经确认的事实或隐藏真相；
- 让 NPC 使用其未获得的信息；
- 把临时裁决自动写成永久规则。

玩家角色知识、各 NPC 知识和主持隐藏信息必须分别维护。

## 临时裁决

规则未覆盖时：
1. 采用与现有 5e 机制最接近的最小裁决；
2. 说明所用判定及依据；
3. 只处理当前缺口；
4. 将裁决记录进存档，供本次战役保持一致；
5. 未经明确修改仓库，不得提升为通用规则。

## 错误修正

发现规则、计算、信息或状态错误时：
1. 明确指出错误；
2. 使用最高有效规则来源或最新确认事实重新核对；
3. 修正可确定的数值与状态；
4. 记录修正内容；
5. 不得隐藏错误或用新的剧情改写掩盖错误。
